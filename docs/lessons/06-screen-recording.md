# Lesson 6: Screen recording that looks like a launch
Principle: capture at 2x the delivery resolution in a clean, staged app state; hide or slow the cursor; zoom only toward the one thing the viewer should notice; re-take rather than fix UI in post.
Example: Lovable 2.0 (https://www.youtube.com/watch?v=xDwR1_vrIg8) cursor-driven zoom onto "Publish" at 57.7 s; floating window with soft shadow, not full-bleed.
Commission-ai: ?demo=promo state, 4K capture for --scale 2, one zoom per shot tied to the shot list's "thing to notice" column.
Exercise: pick one hero v5 shot and name the single pixel region it should zoom to.
