# Lesson 4: How long should it be? Length per platform

Principle: length is set by the job and the place, not by how much you have to show. A launch hero earns about a minute; a feed clip earns 15-45 s; a deep dive can run 10+ min because the viewer chose it. Cut to the shortest length that still lands the five beats.

Example (our reference study): Cursor 2.0 launch 1:04 (9.46M views), Lovable 2.0 1:20 (10.73M), Devin 1:49 (1.23M, one continuous take). Hero v5 is 60 s, right in the band.

Platform caps (check before posting): X non-Premium 2:20; YouTube Shorts up to 3 min; LinkedIn native up to 10 min. The cap is a ceiling, not a target.

Next video: keep the 60 s hero as master; cut a ~20 s X/Shorts version (hook, demo, payoff, ask) and a 30 s feature clip.
