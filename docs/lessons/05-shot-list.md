# Lesson 5: The shot list is the edit, written down first
Principle: before capturing, write one row per shot: beat, what's on screen, the one thing the viewer must notice, on-screen text, length, and the app state needed. Shoot to the list; reshoot from clean moments instead of fixing in post.
Examples: Lovable 2.0 (soft-cut median 1.73 s, cut rate rising to the end); Devin (one continuous take, 3 cuts). Our hero v5 had no problem beat, which a shot list would have exposed.
Exercise: write a 6-row shot list for the 20 s hero cut-down.
