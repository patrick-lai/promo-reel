# my-promo: footage notes

`manifest.yaml` is authoritative; this file is for humans and for the capturing agent. **Raw media is never committed** (no LFS).
Write here: what each take shows, capture caveats (cursor overlay, hidden toasts, clock/seed), what still needs a reshoot.
`promo build|shot|check` verify every referenced clip's sha256; `promo footage verify` runs the same gate.

Capture contract: see `capture/README.md` in the promo-reel repo (DPR 2, 60 fps, 3840x2160 preferred; never edit UI pixels;
record the full app commit + URL params).
